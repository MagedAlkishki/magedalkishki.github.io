04 — How I build

Approach

01

Real tests, not just code that compiles

Every project above ships with a test suite I wrote and actually ran — most against a hand-rolled test harness, since a lot of this was built in sandboxes with no access to the usual package registries.

02

Model the real rule, not a toy version

VCT's actual roster-eligibility policy, a restaurant's real food-cost formula, Elo's actual rating math — I'd rather get a real constraint right than build another generic CRUD demo.

03

Verified from a clean clone

Every repo above gets cloned fresh and rebuilt from scratch before I call it done — "works on my machine" isn't good enough.

04

Honest about where I am

Java and JavaScript are where I'm proficient. Everything else on this page is real, working, tested exposure — labeled as exactly that, not inflated.
